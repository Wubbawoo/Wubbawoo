### 🎣 What I'm building

**Deep Water Catch** — a fishing tycoon game in Roblox:
- 🎲 RNG-based catches tied to fish weight & size, with rare mutations
- 💰 Sell your haul to an NPC, priced off those stats
- 🗺️ Unlock new fishing areas as you progress
- 🎣 Buy better rods to reach rarer fish

### 🌱 Currently learning

Roblox Lua — this is my first coding project, so everything here is part of
learning the fundamentals: variables, events, RNG, and data stores.
